# 收藏夹画板整理员 · 使用说明

收藏夹画板整理员（英文标识 `social-favboard-Librarian`）是你的 Obsidian 收藏整理助手。

> 项目前身（只有浏览器扩展 + Obsidian 插件、没有 Skill 的版本）叫「收藏夹画板」。

把草稿白板里散落的收藏视频卡片，按你定义好的「体 / 面 / 线 / 点」自动归类，并排成横向树杈。
**它只动草稿白板，绝不碰你已经整理好的最终白板。**

---

## 一、安装

1. 把 `social-favboard-Librarian` 整个目录放到 CodeArts Agent 的 skills 目录（工作区级或用户级均可）。
2. 开新会话，确认 Agent 能识别 `social-favboard-Librarian`。
3. 不需要安装任何 Python 第三方库，脚本只用标准库。

---

## 二、第一次使用

在 CodeArts 对话框里说：

> 整理草稿白板

或直接说：

> 把白板里的收藏视频按体/面归类

skill 会自己找到你的 vault：

- 读 Obsidian 的 vault 列表
- 找到装了 `social-favboard` 插件的那个 vault
- 再从插件设置里读「默认写入白板」

**白板叫什么名字、放在哪，都以插件设置为准。** 你把 `草稿白板.canvas` 改成别的名字，skill 会跟着改，不用告诉它。
如果电脑上有多个 vault，它只会问你一次，之后记住。

---

## 三、⚠️ 两个"自动写入"开关，别搞混

插件设置里有两个开关，作用完全不同：

| 开关 | 谁触发 | 对白板做什么 |
|---|---|---|
| **新采集的视频自动写入白板** | 浏览器扩展收到新收藏 | **追加**新卡片到草稿白板 |
| **Skill整理排版白板-自动覆盖白板（会覆盖用户自己的排版）** | Skill 生成排版文件 | **整块替换**草稿白板 |

建议用法：

- 采集时：开「新采集的视频自动写入白板」，关「Skill整理排版白板-自动覆盖白板（会覆盖用户自己的排版）」
- 整理时：关「新采集的视频自动写入白板」，开「Skill整理排版白板-自动覆盖白板（会覆盖用户自己的排版）」
- 两个同时长时间开着会互相覆盖

两个开关**默认都是关闭**的。如果之前装过旧版插件，`data.json` 里可能还存着旧值，需要手动关一次。

skill 每次动手前会检查「新采集的视频自动写入白板」；发现是开的，会先提醒你。

### 「Skill整理排版白板-自动覆盖白板（会覆盖用户自己的排版）」的好处与坏处（默认关闭）

**好处**

- 一次能写任意多张：插件整块替换白板，不受"逐条编辑"的次数限制
- 全自动：打开自动覆盖开关后，不用按 Ctrl+P
- 结果确定：白板内容 = Skill 算好的完整文件
- 替换前自动备份，出错可回滚
- 其他用户也能用，不依赖个人环境

**坏处 / 风险**

- 整块覆盖：你在白板上手动拖过、加过、改过的内容会被覆盖成 Skill 版本
- 和「新采集的视频自动写入白板」同时开时会互相覆盖
- 只能整体更新，不能只改一两张
- 归类出错时会一次性覆盖全部，需要靠备份回滚
- 依赖「Skill 输出文件」路径，换电脑或换 vault 要重新设置
- 开关改动后，需要重启 Obsidian 才生效

**建议**

- 采集时：关「Skill整理排版白板-自动覆盖白板（会覆盖用户自己的排版）」，开「新采集的视频自动写入白板」
- 整理时：反过来
- 不确定时：用 Ctrl+P 手动导入，导入前可以先检查生成的文件

## 四、日常使用流程

```
1. 扩展采集（正常刷收藏页）
        ↓
2. 插件「立即写入」→ 卡片进入草稿白板
        ↓
3. 在 CodeArts 说「整理草稿白板」
        ↓
4. skill 出归属清单 → 你确认或修改
        ↓
5. skill 生成排版文件（自动备份）
        ↓
6. 插件自动写入草稿白板（需开启「Skill整理排版白板-自动覆盖白板（会覆盖用户自己的排版）」）
        ↓
7. 关掉白板再打开 → 看到树杈
        ↓
8. 你手动把整理好的「面」复制到最终白板
```

**第 7 步很重要**：插件把文件写进白板后，Obsidian 里需要**关闭这块白板再重新打开**（或在插件设置里重载一次）才能看到新布局。

## 五、规则（都会按这个执行）

### 一套卡

封面图 + 文本是一个整体，移动、复制、删除都成对进行，不会只挪一半。

### 归类置信度

| 置信度 | 处理方式 |
|---|---|
| 高 | 复制完整套卡到对应概念 |
| 中 | 只在卡片文本**第一行**写「也可归入：游戏 / 美术」，不复制卡 |
| 低 | 不动，留在散卡区 |

### 最多复制 3 份

一条视频最多出现在 **3 个概念**里，3 份内容完全一致。

- 归属 **3 个及以下**：直接执行，不问你
- 归属 **超过 3 个**：先列清单，你确认或删减后才执行

### 主归属

先比语义匹配度；两个概念难分时，用层级兜底：**线优先于面**。

### 不会静默归类

每次整理都会先给你一份清单（在 CodeArts 对话框里），你至少能看到一次归属结果。

### 散卡

归不进任何概念的卡留在原来的位置，只追加、不重排、不额外标注。

### 已分组的卡

已经在分组框里的卡视为"你已分好"，skill 不会重排它们。

## 六、概念库

位置：`<你的 vault>/分类类型-灵感体系.md`（可手改）

结构：

```markdown
# 分类类型-灵感体系

## 体：游戏
描述：独立游戏、玩法设计、美术参考

- 面：游戏美术
  关键词：画风、低多边形、lowpoly、美术
  - 线：赛璐璐
  样例：Lowpolyweirdo: NEYASNOE

- 面：游戏玩法
  关键词：玩法、循环、loop、机制
```

- 新建概念时，skill 会逐层问：体 → 面 → 线（可空）→ 点先不管。
- 允许跳级：体 + 面就能用，面下可直接挂卡。
- 允许后补：线和点以后有素材了再加。
- **新建体/面/白板前，skill 必须先征求你同意。**

## 七、安全与备份

- skill **只写**插件配置的那块草稿白板；目标不是它就拒绝写入。
- 落盘方式：python 只负责计算，真正的写入由 Agent 用文件编辑工具完成（终端没有写 vault 的权限，属于 CodeArts 沙箱限制，不是你的设置问题）。
- 每次写入前备份到工作区：`social-favboard-Librarian/.sf-out/草稿白板.<时间戳>.canvas`
- 回滚：把 `.sf-out` 里的备份复制回 `草稿白板.canvas` 即可。
- **不删除**你的卡片、分组、连线。
- 唯一允许清理的是 skill 自己生成的影子卡（文本第一行带 `SF-SHADOW` 标记），清理前也会备份。
- 新建文件（白板、概念库）前一律先问你。

## 八、常见问题

**找不到白板？**
检查插件设置里「默认写入白板」是否为空；为空时 skill 会提示你去填。

**整理了但 Obsidian 没变化？**
关掉这块白板再打开。插件不监听文件变化。

**为什么有的卡没被归类？**
标题信息不足（比如只有"这个太绝了"），或者还不属于任何已定义概念。它们会留在散卡区。

**同一视频在抖音和小红书都收藏了？**
按你的要求**各留各的**，不合并。

**归类错了怎么办？**
把 `.sf-out` 里的备份复制回 `草稿白板.canvas` 即可；或者在对话里指出哪条不对，skill 调整后重排。
