# 归类与排版规则

## 一套卡

- 一套卡 = 封面图（file）+ 文本（text），不可拆开。
- 复制 = 复制两个节点；移动 = 两个节点一起改坐标。
- 影子卡复用原封面图片路径，不复制图片文件。

## 概念层级

```
体 → 面 → 线 → 点（套卡）
```

- 体和面是必须的；线和点可以后补。
- 允许跳级：面下可以直接挂套卡，没有线。
- 一个面就是一个分组框；面内可以有多条线。
- 不要为体创建分组框，体用最左侧文本卡表达。

## 归属判断

输入（视频侧）：
- 标题
- 作者
- 平台
- 话题/简介（如果文本里有）
- 不使用封面图

输入（概念侧）：
- 名字
- 描述
- 关键词
- 已归入的样例标题

### 置信度

| 置信度 | 判定 | 动作 |
|---|---|---|
| high | 标题/话题与概念描述或样例高度一致 | 复制套卡到该概念 |
| medium | 有相关性但证据不足 | 只在文本第一行写「也可归入：体 / 面」 |
| low | 判不了或标题信息不足 | 不动，留散卡区 |

### 主归属

1. 先比语义匹配度，差距明显时高者为主。
2. 接近难分时按层级：更具体的优先（线 > 面）。
3. 主归属决定完整套卡放在哪里；其余归属按复制规则处理。

### 多归属

- 最多 3 个概念，3 份套卡内容完全一致。
- 超过 3 个：先列清单让用户删减，确认后才执行。
- 3 个及以下：直接执行，不打扰用户。

## 正文标注

中置信时，在文本节点**第一行**加：

```
也可归入：游戏 / 游戏美术
```

- 已存在则不重复追加
- 不改标题、作者、日期、链接
- 放在标题上方

## 排版（横向树杈）

从左到右：

```
体文本卡  →  面分组框  →  线文本节点  →  套卡竖排
```

- 列间距由内容宽度决定，不重叠为准
- 体在最左；每个体的面框纵向堆叠；面框内线和套卡纵向排列
- 不画连线

## 散卡区

- 未归类的套卡留在原位置，不重排、不加标注
- 新建概念后只重扫散卡区
- 已在分组框内的套卡不动

## 路径与写入

- 目标白板必须等于插件 `data.json` 的 `targetCanvas` 解析出的绝对路径
- 不相等 → 拒绝写入
- 写入前备份为 `*.sfbak-<YYYYmmdd-HHMMSS>`
- 写回时保留 `edges`
- 只删自己生成的 `SF-SHADOW` 影子卡

## 概念库

默认位置：`<vault>/分类类型-灵感体系.md`

结构：

```markdown
# 分类类型-灵感体系

## 体：游戏
描述：独立游戏、玩法设计、美术参考

- 面：游戏美术
  关键词：画风、低多边形、lowpoly、美术
  - 线：赛璐璐
  样例：Lowpolyweirdo: NEYASNOE

- 面：游戏玩法
  关键词：玩法、循环、loop、机制
```

- 用户可手改
- skill 只追加/补充，不删除用户写的条目
- 新建体/面前先征求同意
