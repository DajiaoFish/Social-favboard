# 收藏夹画板整理员 · 安装与使用教程

> 项目前身（只有浏览器扩展 + Obsidian 插件、没有 Skill 的版本）叫 **「收藏夹画板」**。
> 加了 Skill 之后，完整名字是 **收藏夹画板整理员（social-favboard-Librarian）**。

本教程分三部分：

1. **安装**：浏览器扩展、Obsidian 插件、Skill 三件套
2. **使用**：采集 → 整理 → 查看归档
3. **规则与常见问题**

---

# 第一部分：安装

## 1.1 浏览器扩展（Chrome / Edge）

1. 打开浏览器扩展管理页
   - Chrome：地址栏输入 `chrome://extensions`
   - Edge：地址栏输入 `edge://extensions`
2. 打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**
4. 选择 `browser-extension` 目录
5. 安装完成后，先在浏览器里登录抖音、B站、小红书

扩展只在你自己的浏览器里读页面已经加载出来的内容，不额外向平台发请求。

![浏览器扩展采集界面](images/01-collect-extension.png)

## 1.2 Obsidian 插件 Social Favboard

1. 把 `social-favboard` 整个目录放进你的 vault：

```
<你的 vault>/.obsidian/plugins/social-favboard/
```

2. 打开 Obsidian → 设置 → **第三方插件** → 关闭安全模式 → 启用 **Social Favboard**
3. 进入插件设置，至少配置两项：
   - **默认写入白板**：草稿白板的相对路径，例如 `草稿白板.canvas`
   - **Skill 输出文件**：`...\social-favboard-Librarian\.sf-out\organized.canvas` 的绝对路径

> 草稿白板必须先在 vault 里创建好，插件不会自动创建文件。


## 1.3 Skill（收藏夹画板整理员）

1. 把 `social-favboard-Librarian` 整个目录放到 CodeArts Agent 的 skills 目录（工作区级或用户级均可）
2. 开一个新会话，确认 Agent 能识别 `social-favboard-Librarian`
3. 不需要安装任何 Python 第三方库，脚本只用标准库

# 第二部分：使用

## 2.1 采集收藏

1. 在浏览器打开抖音 / B站 / 小红书的收藏页
2. 点扩展图标，开始采集
3. 采集结果交给插件：

| 插件开关 | 效果 |
|---|---|
| **立即写入** 按钮 | 手动把当前队列写进草稿白板 |
| **新采集的视频自动写入白板** | 打开后，扩展一采集到就自动追加 |

4. 卡片会进入 **草稿白板**（插件设置里「默认写入白板」指向的那一块）


## 2.2 让 Skill 整理

1. 先把草稿白板的标签页**关掉**（Obsidian 开着会覆盖文件）
2. 在 CodeArts 里说一句：

```
整理白板
```

3. Skill 自动完成：
   - 读取草稿白板里的散卡
   - 读取 `分类类型-灵感体系.md` 里的体和面
   - 判断每张卡属于哪个面
   - 排版（每个面框内每行 3 套，体每行最多 5 个）
   - 生成排版稿 `.sf-out/organized.canvas`
4. 插件发现文件更新后，**自动整块替换**草稿白板（需打开「Skill整理排版白板-自动覆盖白板」）
5. 重新打开草稿白板查看

关于 Ctrl+P：

- **「Skill整理排版白板-自动覆盖白板」开着**：全自动，不需要按 Ctrl+P
- **这个开关关着**：需要手动导入，完整步骤：
  1. 按 `Ctrl + P`
  2. 输入「导入」
  3. 选择「从 Skill 输出文件导入白板」
  4. 回车
  5. 关掉草稿白板再打开


## 2.3 查看与归档

1. 打开草稿白板，确认分组和卡片位置
2. 选中整理好的某个「面」的分组框，复制粘贴到你自己的最终白板
3. 最终白板由你自己管理，Skill **永远不会修改它**

## 2.4 管理分类概念

概念定义在 vault 根目录的：

```
分类类型-灵感体系.md
```

有两种改法：

- **在插件设置里改**：插件设置最底部「分类类型」→ 点体名展开 → `+ 添加体` / `+ 添加面`
- **直接手改文件**：保持格式即可

```markdown
## 体：游戏
- 面：游戏玩法
- 面：游戏美学

## 体：建模
- 面：建模教程
```

> Skill 每次整理都会重新读取这个文件，你改了体/面，下一次整理就按新结构归类。

# 第三部分：规则与常见问题

## 3.1 必须知道的规则

- 一条视频最多复制到 **3 个概念**，3 份内容完全一致
- 超过 3 个概念时，Skill 先出清单让你确认
- 中等置信的视频不会复制卡，只在卡片正文第一行写「也可归入：X」
- 每次写入前自动备份，备份在 `social-favboard-Librarian/.sf-out`，只保留最近 10 份
- Skill 只写草稿白板，**最终白板只读**

## 3.2 常见问题

**Q：卡片没有封面？**
采集时就缺封面文件（`video-covers` 里也没有）。Skill 只能补"有文件但白板缺节点"的情况，真缺的只能重新采集。

**Q：整理完了，白板没变化？**
- 先确认「Skill整理排版白板-自动覆盖白板」是打开的
- 草稿白板标签页关掉再打开
- 自动覆盖只在 `organized.canvas` 重新生成时触发一次，不是一直覆盖
**Q：需要按 Ctrl+P 吗？**

分两种情况：

- **「Skill整理排版白板-自动覆盖白板」开着**：不需要，Skill 生成文件后插件会自动写入
- **这个开关关着**：需要手动导入，完整步骤：
  1. 按 `Ctrl + P`
  2. 输入「导入」
  3. 选择「从 Skill 输出文件导入白板」
  4. 回车
  5. 关掉草稿白板再打开

**Q：我自己拖动的卡片会被改回去吗？**
不会。只有你下次说「整理白板」、Skill 重新生成文件时，才会覆盖一次。日常拖动是安全的。

**Q：分类不准怎么办？**
- 在 `分类类型-灵感体系.md` 里给面加关键词和样例标题
- 或者直接在插件「分类类型」面板里补面
- 也可以手改白板，Skill 不会动已进分组框的卡

**Q：白板里出现重复卡片？**

历史采集/导入可能产生重复。整理时 Skill 会按视频 ID 去重，保留一套并清理重复节点。

**Q：更新插件后没生效？**
插件代码不会热更新。更新文件后必须**完全退出 Obsidian 再打开**，或者 设置 → 第三方插件 → 把 Social Favboard 关掉再打开。只刷新设置页不算重载。

**Q：Skill 说"排完了"，但白板没变化？**
"排完"分两步：

1. Skill 生成排版文件
2. 插件把文件写进白板

只有「Skill整理排版白板-自动覆盖白板」开着，或者你手动执行 `Ctrl+P → 导入`，白板才会真正变化。以后 Skill 会明确区分"文件已生成"和"已写入白板"。

**Q：为什么每次只归一部分，很多没归类？**
Skill 用的是**语义判断**，不是规则匹配：

- 标题清晰、概念描述充分 → 归得准
- 标题含糊、概念没写描述 → 留在散卡区，等你手动处理

它不追求 100% 按你的想法分类，而是把明显能归的归好，剩下的留人工调整。
